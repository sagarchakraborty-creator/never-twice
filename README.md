# Never Twice

A habit tracker built on one rule: **never skip it twice.**

- Each habit has a full version and a small version for comeback days.
- Miss once → the next planned day is your comeback day. Miss twice → the app asks you to come back today, small.
- Sunday weekly review: what did I commit to, what did I miss twice, what needs to change. Then put the comeback on your calendar.
- Data stays on your phone (localStorage). Save a backup from the Habits tab.
